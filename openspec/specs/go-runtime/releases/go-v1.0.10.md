# codex-lb Go 1.0.10

## Прерывание активного ответа Codex

- Исправлена ошибка `Only response.create and response.cancel are supported`: LB теперь принимает используемый Codex кадр `response.interrupt` с `mode: discard_partial_items`.
- Команда передаётся в тот же ChatGPT WebSocket, где выполняется ответ. Подтверждение, события прерывания и итоговый ответ приходят от upstream; LB не подменяет их локальной отменой и не переносит чат на другой аккаунт.
- Фактический расход учитывается один раз; следующий явный `response.create` может продолжить прерванный ответ. Чужой или устаревший ID отклоняется без отмены другой генерации.
- Если итоговый ответ пришёл раньше подтверждения прерывания, ожидание ограничено пятью секундами. При отсутствии подтверждения закрывается только затронутый upstream-сокет, уже известный расход сохраняется. Неотправленная команда не попадает в следующий запрос.

Например, новое сообщение пользователя во время генерации может прервать текущий ответ, после чего Codex отправляет следующий запрос с `previous_response_id`. Новые клиентские настройки не требуются. Публичный `response.steer` и private Codex interruption для внешних Model sources в этот релиз не входят.

## Основная ветка

Полная существующая Go-реализация вместе с этим исправлением переносится из `fork` в `main` без переписывания истории. Старый Python-код остаётся доступен в предыдущих коммитах и тегах; восстанавливать `legacy/` для работы Go-версии не нужно.

## Обновление

Относительно go-v1.0.9 схема SQLite **33**, протокол обновления **1** и настройки не меняются. Обновление возможно через **Settings → Runtime updates** или ручной заменой бинарника с сохранением каталога данных и ключа шифрования. Перед ручной заменой сделайте согласованную резервную копию. Переход со старого Python-runtime по-прежнему требует отдельного импорта данных, а не простой подмены исполняемого файла.

Архивы Linux amd64/arm64 содержат статический `codex-lb` со встроенной админкой, лицензии и необязательный шаблон systemd. Проверьте `SHA256SUMS`; `./codex-lb version` должен показать `go-v1.0.10`.

## Проверки и ограничения

Прошли по 1391 Go-тесту в обычном режиме и с `-race`, `go vet ./...` и сборка админки. Локальные WebSocket-проверки охватывают полный маршрут LB → provider adapter → upstream, четыре варианта маршрута, гонки подтверждения и завершения, сохранение расхода, продолжение ответа, авторизацию и изоляцию параллельных соединений. Строгие проверки изменения и go-runtime пройдены; общая strict OpenSpec validation сохраняет 22 прежних замечания в незатронутых спецификациях.

Реальные провайдеры и запуск на физическом ARM не проверялись. Публикация релиза сама по себе не обновляет локальный сервис или VPS.
