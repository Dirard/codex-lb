# Go v1.8.0 — отдельная генерация видео через подписки Grok

## Изменения

- Новая функция **Генерация видео**, отдельная от пула ChatGPT. С ним она делит только API-ключ codex-lb. Аккаунты Grok лежат в своих таблицах, поэтому ни текстовые маршруты, ни отчёты, ни лимиты ключей их не видят.
- Новая страница **Video** в дашборде:
  - аккаунты пула: импорт, пауза, удаление;
  - разрешённые ключи;
  - итоги и последние задания.
- Отдельный REST с тем же ключом:
  - `POST /video/v1/generations` — создать задание, ответ 202 с локальным `id`;
  - `GET /video/v1/generations/{id}` — статус, ссылка на ролик и стоимость;
  - `GET /video/v1/generations` — задания этого ключа.
- Входные данные: текст, первый кадр, последний кадр, до 4 промежуточных кадров, референсы, длина от 1 до 15 секунд, разрешение до 1080p. Первый и последний кадр, промежуточные кадры и референсы работают только на `grok-imagine-video-1.5`.
- Несколько аккаунтов:
  - задание уходит на наименее занятый аккаунт, не больше 4 незавершённых заданий на аккаунт, и остаётся на нём;
  - 401 после обновления токена, 403 или 429 переводят запрос на другой аккаунт, всего пробуется не больше 4;
  - запрос, который мог начать выполняться, повторно не отправляется.

## Как подключить

1. На своей машине войдите официальным CLI, для каждого аккаунта в отдельной папке: `GROK_HOME=/tmp/grok-one grok login --device-auth`.
2. Импортируйте `auth.json` на странице **Video** и удалите файл. При импорте токен сразу обновляется, поэтому копия CLI больше не нужна.
3. Добавьте свой API-ключ в разрешённые. До этого ключ получает 403 `video_access_denied`.

## Обновление

Схема SQLite **44**. Миграция только создаёт пустые таблицы, поэтому аддитивна: предыдущая версия продолжает работать во время передачи, и откат безопасен. Протоколы обновления и передачи не меняются. С go-v1.2.0 – go-v1.7.2 обновление из **Settings → Runtime updates** проходит без простоя.

## Проверки и ограничения

- Гейты CI на GitHub недоступны, поэтому прогнаны локально: `go vet`, `golangci-lint`, `go test`, `go test -race`, `govulncheck`, тесты дашборда, сборка, контрактные тесты и `openspec validate`.
- Маршрутные тесты используют локальную заглушку xAI. Реальные запросы к xAI в тестах не отправляются.
- Проба 31.10.2026 с подпиской: `grok-imagine-video-1.5` с первым кадром, последним кадром и текстом, 2 секунды, 480p, готово за 30 секунд, xAI сообщил стоимость $0,18. Обновление токена вне CLI и отзыв сессии тоже проверены.
- Путь через подписку использует OAuth-клиент официального CLI: xAI не публикует способа зарегистрировать свой. xAI может это прекратить или запретить, риск лежит на владельце аккаунтов.
- Остаток недельного пула через API недоступен, смотрите вкладку Usage на сайте xAI. Отказ при исчерпании лимита на практике не наблюдался и обрабатывается по HTTP-статусу.
- `cost_usd` — это стоимость, которую сообщает xAI, а не списание с подписки. Лимитов на видео по ключам пока нет: единственный контроль — список разрешённых ключей.
- Ссылка на ролик принадлежит xAI и доступна любому, у кого она есть.
- Публикация релиза сама по себе не обновляет сервер.
