# Go v1.18.0 — версия клиента Antigravity в настройках

## Изменения

- Версия клиента Antigravity, которую codex-lb показывает Google в User-Agent, теперь задаётся в дашборде: **Settings → Antigravity client**, рядом с «Codex client». По умолчанию `2.34.0`, формат `MAJOR.MINOR.PATCH`.
- Сохранённая версия действует без перезапуска со следующего входа, обновления моделей и запроса каждого источника Antigravity. Её стоит поднять, если Google перестанет отдавать новые модели старым клиентам.
- `GET`/`PUT /api/settings` возвращают и принимают поле `antigravityClientVersion`. Неверный формат отклоняется с 422, а не строковое значение — с 400.
- Переменная окружения `CODEX_LB_ANTIGRAVITY_CLIENT_VERSION` из go-v1.17.0 больше не читается: единственный источник — настройка.

## Обновление

Миграция 53 добавляет столбец `runtime_settings.antigravity_client_version` со значением `2.34.0`. Она аддитивная и мгновенная, поэтому обновление из **Settings → Runtime updates** с go-v1.2.0 – go-v1.17.0 проходит без простоя. Протоколы обновления и передачи не менялись.

## Проверки и ограничения

- Гейты прогнаны локально, а не в CI: `go vet`, `golangci-lint`, `go test`, `go test -race`, `govulncheck`, `openspec validate`, тесты дашборда, сборка и контрактные тесты на собранном бинарнике.
- Тесты проверяют:
  - сохранение настройки и отказ на неверных значениях в SQLite и admin API;
  - что новая версия попадает в User-Agent следующего запроса без перезапуска;
  - что запрос при нечитаемой настройке отклоняется до отправки в Google;
  - что раздел дашборда отправляет только версию.
- Релиз собран вручную и не подписан: ключ подписи есть только в CI.
- Публикация релиза сама по себе не обновляет сервер.
