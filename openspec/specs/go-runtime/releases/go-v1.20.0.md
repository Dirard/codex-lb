# Go v1.20.0 — откат аккаунтов Antigravity

## Изменения

- Аккаунты Google Antigravity убраны полностью, codex-lb снова работает как в go-v1.16.0. Удалены:
  - вход через Google;
  - перевод запросов в Cloud Code;
  - транспорт с профилем Chrome 123 из go-v1.19.0;
  - раздел «Antigravity client» в настройках;
  - всё, что касается Antigravity, на странице Model sources.
- При обновлении все источники Antigravity удаляются так же, как при ручном удалении: вместе с аккаунтом, refresh-токеном Google, привязками к группам и ключам и закреплёнными разговорами. История запросов и отчёты остаются.
- Опция «Keep conversations here» из go-v1.16.0 остаётся для всех аккаунтов.
- Возвращён каталог `openspec/` (спецификации и архив изменений), удалённый вместе с правками Antigravity.

## Обновление

Миграция 55 удаляет источники Antigravity. Она аддитивная и проходит за доли секунды, поэтому обновление из **Settings → Runtime updates** с go-v1.2.0 – go-v1.19.0 проходит без простоя. Миграции 53 и 54 остаются, как требует порядок только-добавляемых миграций; их столбец `runtime_settings.antigravity_client_version` больше не читается. Протоколы обновления и передачи не менялись.

Аккаунт Google, подключённый через Antigravity, после обновления больше не используется. Если хотите отозвать доступ и на стороне Google, удалите приложение Antigravity на странице доступа аккаунта Google.

## Проверки и ограничения

- Гейты прогнаны локально, а не в CI: `go vet`, `golangci-lint`, `go test`, `govulncheck`, `openspec validate`, тесты дашборда, сборка и контрактные тесты на собранном бинарнике.
- Тест миграции: база в схеме 54 с активным и удалённым источником Antigravity и источником Z.AI переходит на 55. Оба источника Antigravity и их токены удалены, источник Z.AI и история запросов не тронуты.
- Публичные значения OAuth-клиента Antigravity остаются в истории Git, но код их больше не использует.
- Релиз собран вручную и не подписан: ключ подписи есть только в CI.
- Публикация релиза сама по себе не обновляет сервер.
