# Go v1.9.0 — вход в аккаунты Grok прямо из дашборда

## Изменения

- Аккаунты Grok теперь добавляются на странице **Video**: кнопка **Add account** показывает ссылку и код xAI, вы подтверждаете вход, и аккаунт появляется в пуле. CLI и файл с токенами больше не нужны.
- Вход в аккаунт, который уже есть в пуле, обновляет его сессию. Для аккаунта в статусе **Needs a new sign-in** на странице есть кнопка **Sign in again**.
- Импорт файла и маршрут `POST /api/video/accounts/import` из go-v1.8.0 удалены. Вместо него `POST /api/video/accounts/login`, `GET` и `DELETE /api/video/accounts/login/{id}`. Аккаунты, импортированные в go-v1.8.0, продолжают работать.
- Запрашиваются только нужные права: `openid profile email offline_access api:access`.

## Обновление

Схема SQLite не меняется (**44**), протоколы обновления и передачи тоже. С go-v1.2.0 – go-v1.8.0 обновление из **Settings → Runtime updates** проходит без простоя. Начатый вход живёт в памяти процесса, поэтому если обновление случилось во время входа, начните его заново.

## Проверки и ограничения

- Гейты прогнаны локально, а не в CI: `go vet`, `golangci-lint`, `go test`, `govulncheck`, тесты дашборда, сборка, контрактные тесты и `openspec validate`. `go test -race` прошёл для всех пакетов, кроме `internal/adapters/sqlite`: его прервали решением владельца после 19 минут, потому что код этого пакета с go-v1.8.0 не менялся. Обычный `go test` этот пакет прошёл.
- Сквозная проверка 31.10.2026 на собранном бинаре с реальным входом через API дашборда: аккаунт добавлен, через `/video/v1/generations` создан ролик на `grok-imagine-video-1.5` с первым кадром, последним кадром и текстом (1 секунда, 480p, готово за 28 секунд, xAI сообщил стоимость $0,10), затем аккаунт удалён с отзывом сессии. В логах сервера токенов и картинок нет. Сам диалог в браузере проверен только тестами дашборда с заглушками.
- В codex-lb встроен публичный `client_id` официального Grok CLI, потому что xAI не публикует способа зарегистрировать свой. xAI может это прекратить или запретить, риск лежит на владельце аккаунтов.
- Остаток недельного пула через API недоступен, смотрите вкладку Usage на сайте xAI. Отказ при исчерпании лимита на практике не наблюдался.
- Публикация релиза сама по себе не обновляет сервер.
