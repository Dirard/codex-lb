# codex-lb Go 1.0.4

## Что изменилось

- В Settings → Account groups добавлена кнопка **Reset period** с подтверждением. Она обнуляет расход действующих лимитов всех текущих ключей группы, включая выключенные, и запускает новые учётные периоды. История запросов, настройки лимитов, квоты аккаунтов и купленные кредиты не меняются.
- Запросы, начатые до сброса, сохраняют свой учёт: их позднее завершение не начисляет расход в новые периоды. Повторные сбросы в один момент времени не смешивают периоды. Удалённые и внутренние ключи не затрагиваются.
- Исправлен доступ сгруппированных ключей к **Model sources**. Группа ограничивает ChatGPT-аккаунты; внешние источники отдельно управляются настройкой Assigned model sources. Разрешённая модель Z.AI доступна в каталоге LB и для выполнения запросов без добавления источника в ChatGPT-группу.
- Правила источников согласованы для новых запросов, продолжения диалога и резервирования лимитов. Явно запрещённые источники и ChatGPT-аккаунты вне группы остаются закрыты; проверки ключей, модели, учёта и egress сохранены.

## Ограничения

Этот релиз исправляет серверный каталог и доступ к источникам, но не добавляет автосинхронизацию меню моделей самого Codex. В проверенном Codex CLI 0.159.0 пользовательский провайдер использовал встроенный каталог без запроса `/models`; отдельно подключённый `model_catalog_json` читался при запуске. Конфигурация клиентов этой публикацией не меняется. Отсутствие `gpt-6.1-sol` у отдельного клиента не объявляется исправленным: разрешённая модель присутствует в проверенном ответе сервера, причина на том клиенте не установлена.

## Установка и совместимость

Относительно Go 1.0.3 миграция схемы БД не требуется. Перед обновлением сохраните согласованную резервную копию БД и соответствующего ключа шифрования. Используйте прежние каталог данных и конфигурацию. Старый бинарник можно сохранить для отката; откат бинарника не отменяет уже выполненный ручной сброс лимитов. Обновление и перезапуск VPS выполняются отдельно с учётом активных потоков.

Архивы `linux-amd64` (x86-64) и `linux-arm64` содержат статический бинарник `codex-lb` со встроенной админкой, тексты лицензий и шаблон systemd. Node.js и Python для работы сервера не нужны. Проверьте архив через `sha256sum -c SHA256SUMS`; `./codex-lb version` должен вывести `go-v1.0.4`.
