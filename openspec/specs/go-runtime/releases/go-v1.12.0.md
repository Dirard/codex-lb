# Go v1.12.0 — голос для сторонних приложений через Realtime API

## Изменения

- codex-lb принимает стандартный OpenAI Realtime API, и сторонние приложения могут работать с голосом через пул подписок ChatGPT по обычным ключам codex-lb:
  - **WebSocket.** `wss://<host>/v1/realtime?model=gpt-realtime` открывает голосовую сессию на одном аккаунте пула. События ходят без изменений в обе стороны: `session.update`, `input_audio_buffer.append`, `response.create` и ответы модели. Так работают серверные приложения и SDK (OpenAI Agents SDK, pipecat, LiveKit).
  - **WebRTC.** `POST /v1/realtime/calls` принимает SDP-оффер как `application/sdp`, `multipart/form-data` (поля `sdp` и `session`) или JSON `{sdp, session}`. Подписка ChatGPT принимает только JSON, поэтому codex-lb собирает его сам. В ответ приходят SDP и `Location: /v1/realtime/calls/<id>`. Сайдбенд звонка доступен как раньше, через `/v1/realtime?call_id=<id>`.
  - **Ключи для браузера.** `POST /v1/realtime/client_secrets` с ключом codex-lb выдаёт короткоживущий секрет `ek_…` (по умолчанию на 10 минут, можно от 10 секунд до 2 часов) с необязательной сессией. Браузер передаёт его как `Authorization: Bearer ek_…` в `/v1/realtime/calls` или как подпротокол WebSocket `openai-insecure-api-key.ek_…` вместе с `realtime`. Сессия из секрета отправляется модели первым сообщением.
- **Учёт.** Голосовая WebSocket-сессия резервирует бюджет на ключе ($1.28: 20 000 входных и 10 000 выходных аудиотокенов) и после закрытия один раз списывает фактический расход по всем `response.done` по ценам OpenAI: текст и аудио отдельно, у `gpt-realtime-mini` свои цены. Звонки WebRTC записываются без токенов, потому что звук идёт напрямую между приложением и OpenAI.
- Голос Codex (`/backend-api/codex/realtime/calls` и его сайдбенды) работает по-прежнему.

## Обновление

Схема SQLite **49**. Миграция только добавляет таблицу `realtime_client_secrets`, поэтому аддитивна: предыдущая версия продолжает работать во время передачи, и откат безопасен. Протоколы обновления и передачи не меняются. С go-v1.2.0 – go-v1.11.1 обновление из **Settings → Runtime updates** проходит без простоя.

## Проверки и ограничения

- Гейты прогнаны локально, а не в CI: `go vet`, `golangci-lint`, `go test`, `go test -race` (четыре шарда, как в CI), `govulncheck`, тесты дашборда, сборка, контрактные тесты и `openspec validate`.
- Форма запросов сверена с пробами с прода 03.11.2026 с разрешения владельца:
  - стандартный WebSocket `gpt-realtime` по токену подписки принял `session.update` и ответил текстом с данными о расходе;
  - бэкенд подписки создал звонок из JSON `{sdp, session}`, а чистый SDP и multipart отклонил.
- Живой звонок WebRTC с настоящим звуком через `/v1/realtime/calls` и сессия через версию из этого релиза ещё не проверялись.
- Как голосовые сессии расходуют лимиты Codex на аккаунте, не измерено. На здоровье аккаунта сессии не влияют.
- Аккаунт для сессии выбирается так же, как для звонков Codex: первый активный аккаунт ChatGPT, доступный ключу. Распределения по нагрузке нет.
- Цены моделей новее `gpt-realtime` и `gpt-realtime-mini` считаются по цене их семейства.
- Релиз собран вручную и не подписан: ключ подписи есть только в CI.
- Публикация релиза сама по себе не обновляет сервер.
