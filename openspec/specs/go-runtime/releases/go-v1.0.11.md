# Go v1.0.11 — исправления безопасности Go и воспроизводимые релизы

## Безопасность

- Сервер собран Go **1.26.10** вместо 1.26.6. Это закрывает 11 уязвимостей стандартной библиотеки, которые govulncheck находил в достижимом коде: `net/http`, `net/textproto`, `crypto/tls`, `crypto/x509` (GO-2026-6603, -6605, -6607, -6608, -6609, -6610, -6611, -6612, -6613, -6617, -6809). После обновления `govulncheck ./...` не находит достижимых уязвимостей.
- Обновлены `golang.org/x/crypto` 0.58.0 и `golang.org/x/sys` 0.49.0.

## Исправления

- Транскрипция аудио снова передаёт провайдеру MIME-тип файла от клиента (например `audio/webm; codecs=opus`) вместо всегда `application/octet-stream`. Некорректное значение заменяется на `application/octet-stream` и не попадает в заголовок части.
- Ошибка запуска при занятом или недоступном адресе теперь называет адрес и причину, например `cannot bind HTTP listen address 127.0.0.1:2455: address already in use`.

## Сборка и выпуск

- Релизы собираются в GitHub Actions из тега скриптом `scripts/release.sh`. Архивы детерминированы: повторная сборка того же коммита даёт те же `SHA256SUMS`. Состав архива прежний: `codex-lb`, `LICENSE`, `LICENSE.codex-relay`, `codex-lb.service`.
- Каждый pull request и `main` проходят `go vet`, `golangci-lint`, `go test`, `go test -race`, `govulncheck`, проверки дашборда и OpenSpec.
- Чистый checkout компилируется без предварительной сборки дашборда; без собранных ассетов админка отвечает 503 «assets are not built».

## Обновление

Схема SQLite **33**, протокол обновления **1** и настройки не меняются, поэтому обновление возможно через **Settings → Runtime updates** или ручной заменой бинарника с сохранением каталога данных и ключа шифрования. Перед ручной заменой сделайте согласованную резервную копию.

Архивы Linux amd64/arm64 содержат статический `codex-lb` со встроенной админкой, лицензии и необязательный шаблон systemd. Проверьте `SHA256SUMS`; `./codex-lb version` должен показать `go-v1.0.11`.

## Проверки и ограничения

Прошли `go vet ./...`, `golangci-lint`, полный `go test ./...` и `go test -race ./...`, `govulncheck`, lint и typecheck дашборда, `openspec validate --specs`. Реальные провайдеры не использовались. Публикация релиза сама по себе не обновляет локальный сервис или VPS.

Контракт: [Go runtime](https://github.com/Dirard/codex-lb/blob/go-v1.0.11/openspec/specs/go-runtime/spec.md).
