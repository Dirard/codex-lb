# Go v1.5.1 — быстрая карточка темпа на странице групп

## Изменения

- `GET /api/dashboard/projections`, на котором работает карточка недельного темпа кредитов на странице **Группы**, больше не считает атрибуцию ключей — список `topApiKeys`. Её не показывает ни одна страница с тех пор, как обзор заменил старый дашборд, но на её расчёт уходила большая часть ответа: группировка всех сырых событий за последние 2 часа. При ~10 тыс. запросов в час это 20 тыс. событий и почти все 221 мс ответа на копии рабочей базы. Остальные поля карточки — запас, прогноз исчерпания, ближайшее восстановление, рекомендации — не меняются.
- Поле `topApiKeys` в ответе осталось и всегда пустое. Устаревший `GET /api/dashboard/overview` по-прежнему считает атрибуцию для вкладок, открытых до редизайна, пока его не удалят.

## Обновление

Схема SQLite не меняется (**43**), протоколы обновления и передачи тоже. С go-v1.2.0 – go-v1.5.0 обновление из **Settings → Runtime updates** проходит без простоя.

## Проверки и ограничения

Прошли `go vet`, `golangci-lint`, полный `go test` и `go test -race` (в CI четырьмя шардами), `govulncheck`, тесты дашборда, `openspec validate`. Регрессионный тест подтверждает, что `projections` возвращает пустую атрибуцию и не читает `usage_events`, а темп совпадает с темпом устаревшего обзора во всём, кроме атрибуции. Без исправления тест падает. Реальные провайдеры не использовались. Публикация релиза сама по себе не обновляет сервер.
