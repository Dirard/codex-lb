# Go v1.10.5 — срок подписки берётся из ChatGPT

## Изменения

- Срок подписки на странице **Accounts** теперь берётся из ChatGPT. Раньше он брался из ID-токена, а OpenAI записывает его туда при входе и не меняет при обновлении токена, поэтому оплаченные аккаунты выглядели истёкшими.
- Опрос использования не чаще раза в 15 минут на аккаунт читает `GET /backend-api/subscriptions` и хранит в памяти `active_until` и признак продления `will_renew`. `GET /api/accounts` отдаёт их в новом поле `subscription` (`activeUntil`, `willRenew`, `observedAt`); `subscriptionActiveUntil` остаётся.
- Формат прежний: «Subscription: N / +14d: M», но от даты из ChatGPT. В подсказке видны дата, время проверки и продлится ли подписка. «Subscription ended» показывается, только если проверка после срока подтвердила окончание; иначе остаётся «Recorded period ended».

## Обновление

Схема SQLite не меняется (48), протоколы обновления и передачи тоже. С go-v1.2.0 – go-v1.10.4 обновление из **Settings → Runtime updates** проходит без простоя. Прочитанные сроки хранятся только в памяти, поэтому сразу после обновления, до первого опроса (около минуты), показывается дата из токена.

## Проверки и ограничения

- Гейты прогнаны локально: `go vet`, `golangci-lint`, `go test`, `go test -race` (четыре шарда), `govulncheck`, тесты дашборда, сборка, контрактные тесты и `openspec validate`.
- Эндпоинт не документирован. Он проверен 2026-11-02 одним запросом на чтение с разрешения владельца. Ответ для бесплатного аккаунта, отменённой подписки и места в командном workspace не наблюдался: если в ответе нет `active_until`, чтение считается неудачным и остаётся дата из токена.
- Аккаунты на паузе, требующие повторного входа и деактивированные не опрашиваются, как и для использования. Для них остаётся последнее прочитанное значение этого процесса или дата из токена.
- Добавляется около четырёх запросов в час на аккаунт к примерно 120 запросам использования и reset credits.
- Релиз собран вручную и не подписан: ключ подписи есть только в CI.
- Публикация релиза сама по себе не обновляет сервер.
