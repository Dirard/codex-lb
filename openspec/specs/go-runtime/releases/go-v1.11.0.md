# Go v1.11.0 — текстовые модели Grok из подписки SuperGrok

## Изменения

- Новый тип источника моделей **Grok subscription (SuperGrok)**. Grok-аккаунт, в который уже выполнен вход на странице **Video**, теперь обслуживает и текст: его модели (`grok-4.7`, `grok-4.6`, `grok-4.5`, `grok-4.3`, `grok-4.20`, `grok-build-0.1` и другие, которые отдаёт xAI) появляются в общем списке моделей Codex рядом с моделями ChatGPT и других источников.
- Источник не хранит API-ключ. Для каждого запроса он берёт текущий OAuth-токен аккаунта из пула Grok, а пул обновляет этот токен сам. Если xAI отклонит токен до начала ответа, запрос один раз повторяется с обновлённым токеном. Токен отправляется только на `https://api.x.ai/v1`.
- Список моделей и цены xAI берёт при создании источника из `GET /v1/language-models`. Окно контекста выставляется 256 000 токенов, его можно поменять в источнике.
- Расход идёт из недельного пула подписки, общего с видео, а не с баланса API.
- Доступ по ключам работает как у любого источника моделей: по умолчанию источник доступен всем ключам, а ограничить его можно в настройках ключа (назначенные источники).

## Как подключить

1. **Settings → Model sources → Add source**.
2. **Provider → Grok subscription (SuperGrok)**, выберите аккаунт, нажмите **Create**.
3. Модели появятся у Codex после обновления списка моделей, например при новом запуске.

Если аккаунт требует повторного входа, запросы к источнику завершаются ошибкой `grok_account_unavailable` до обращения к xAI и ничего не списывают. Пауза аккаунта на странице **Video** останавливает только видео.

## Обновление

Схема SQLite не меняется (48): привязка к аккаунту хранится в существующей настройке источника. Протоколы обновления и передачи тоже не меняются. С go-v1.2.0 – go-v1.10.6 обновление из **Settings → Runtime updates** проходит без простоя.

## Проверки и ограничения

- Гейты прогнаны локально, а не в CI: `go vet`, `golangci-lint`, `go test`, `go test -race` (четыре шарда, как в CI), `govulncheck`, тесты дашборда, сборка, контрактные тесты и `openspec validate`.
- Тесты маршрута используют локальную заглушку xAI. Формат запроса и ответа сверен с одним настоящим запросом к подписке 02.11.2026: `grok-4.7` вернул рассуждение и вызов функции, `prepaidBalance` остался 0. Полная цепочка через прод на этой версии ещё не проверялась.
- Стоимость считается по ценам xAI за токены. В пробном запросе xAI насчитал примерно треть такой оценки; причина неизвестна, поэтому отчёты могут показывать завышенные расходы.
- Не проверено, принимает ли xAI `reasoning.effort` от Codex, поэтому уровни рассуждения для моделей Grok не объявляются.
- Как xAI отвечает на исчерпанный недельный пул, пока не видели. Такой ответ обрабатывается общими правилами внешних источников.
- Новые модели xAI в существующий источник сами не добавляются: чтобы их получить, создайте источник заново.
- Условия xAI запрещают передавать аккаунт другим людям. Если источником пользуются чужие ключи, ограничьте их через назначенные источники.
- Релиз собран вручную и не подписан: ключ подписи есть только в CI.
- Публикация релиза сама по себе не обновляет сервер.
